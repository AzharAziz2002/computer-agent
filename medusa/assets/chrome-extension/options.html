Medusa Browser Relay

Lets the Medusa agent open its own tabs in your browser

Relay URL: http://127.0.0.1:18792/

How it works

  1. Install this extension once (you already did).
  2. Start Medusa with profile="chrome" — the relay server starts automatically.
  3. The extension auto-connects to the relay (badge shows ON).
  4. Medusa opens its own tabs grouped under a Medusa tab group.
  5. Your existing tabs are never touched — Medusa only controls tabs it creates.
